## 🌟 About Project

E-Nagar Seva is a smart municipal complaint system where citizens can raise issues and officers can resolve them with proof.

---

## ⚡ Features

✨ Citizen Complaint System
✨ Officer Dashboard
✨ Status Tracking (Pending → Completed)
✨ Image Proof Upload
✨ Notifications System
✨ Category-Based Filtering
